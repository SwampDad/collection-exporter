# CurseForge listing material — Collection Exporter 0.3.0

## Summary

Collection Exporter is a client-only, read-only Cobblemon PC collection viewer and clipboard
report exporter. Browse Custom Skins, Legend & Mythic, Shiny, or All Pokémon in a native,
scrollable screen. Optionally show one-based PC box and position locations for each instance.

## Installation

Install the runtime JAR in a Fabric 1.21.1 client's `mods` folder. Keep only one Collection
Exporter JAR installed, then restart Minecraft. This is a client mod; do not install it on the
server.

## Requirements

| Requirement | Version |
| --- | --- |
| Minecraft | 1.21.1 |
| Fabric Loader | 0.18.0 or newer |
| Fabric API | 0.116.7+1.21.1 or newer |
| Cobblemon | 1.8.2 |
| Java | 21 or newer |

PC Plus and PC Exporter are not required.

## Features

- Client-synchronized PC collection reports; no PC screen needs to be open.
- Custom skin families, Legendary/Mythical, shiny, and Other sections.
- Independent PC location display in the viewer and clipboard report.
- Refresh, clipboard export, partial-data warnings, and unknown-aspect visibility.
- No networking, commands, telemetry, mutation, or gameplay automation.
