# Collection Exporter 0.3.0

First stable release of the client-only, read-only Cobblemon collection viewer and clipboard
report exporter for Minecraft 1.21.1.

## Highlights

- Browse a scrollable categorized report directly in Minecraft.
- Filter Custom Skins, Legend & Mythic, Shiny, or All Pokémon.
- Turn on Show PC Locations to see each instance's `Box N, Pos. N` location in the viewer and
  copied report.
- Refresh the client-synchronized PC store on demand and receive explicit partial/unavailable
  status rather than a misleading complete report.
- Copy the organized report to the native Minecraft clipboard.
- See the installed version in the screen's unobtrusive bottom-right metadata label.

## Requirements

- Minecraft 1.21.1
- Fabric Loader 0.18.0 or newer
- Fabric API 0.116.7+1.21.1 or newer
- Cobblemon 1.8.2
- Java 21 or newer

Client-only. PC Plus and PC Exporter are not required.
