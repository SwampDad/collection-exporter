# Changelog

## 0.3.0 — 2026-10-22

First stable release.

- Added the integrated scrollable collection viewer with collapsible categories, responsive
  filter wrapping, mouse-wheel scrolling, and a draggable scrollbar.
- Added the independent Show PC Locations toggle for the viewer and copied report. Grouped
  duplicates retain their individual, one-based box and position values.
- Refined skin, shiny, Legendary, Mythical, custom-species, unresolved-aspect, and
  completeness presentation.
- Added the installed metadata version label to the bottom-right of the main screen.
- Retained client-only, read-only operation without a PC Plus dependency.
